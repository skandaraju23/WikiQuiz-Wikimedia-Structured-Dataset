# 📚 WikiQuiz: Wikimedia Structured Wikipedia Dataset

An interactive trivia quiz generator built with **Gradio** and **Pandas**, powered by the **Wikimedia Structured Wikipedia Dataset**. Developed during the **WikiClub Tech - Open Source Day**.

---

## 🚀 Features

* **Smart Topic Search:** Searches articles by exact title, prefix, keyword match, and full text (abstract/description).
* **Automatic Question Generation:** Extracts dynamic fill-in-the-blank questions focusing on key dates, numbers, and vocabulary.
* **Smart Distractors:** Generates context-aware multiple-choice answers (A, B, C, D) alongside safety fallbacks.
* **Timed Quiz Sessions:** Configurable 30-second timer per question with automated submission on timeout.
* **Interactive UI:** Clean, responsive web interface built using Gradio Blocks.
